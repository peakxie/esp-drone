│ PROBLEM #1: INTEGRAL WINDUP                                               │
│ ├─ Location: controller_pid.c, line 157                                   │
│ ├─ Issue:    PID only resets when thrust == 0                             │
│ ├─ Effect:   During slow ramp (0→230), integral accumulates for 500ms     │
│ ├─ Result:   Integral saturates to ±33.3 × KI(440) = ±14,652 correction  │
│ └─ Impact:   Massive oversized correction at critical liftoff moment      │
│                                                                             │
│ PROBLEM #2: MOTOR CLIPPING                                                │
│ ├─ Location: num.c, lines 85-97 & power_distribution_stock.c, line 81     │
│ ├─ Issue:    limitThrust() hard clips negative motor values to 0          │
│ ├─ Effect:   When M = thrust - correction = 230 - 14,652 = -14,422       │
│ ├─ Result:   Motor output clipped to 0 (motor stops completely)           │
│ └─ Impact:   Two opposite motors disabled, two maxed → asymmetric failure │
