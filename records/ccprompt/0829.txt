ESP-Drone 自稳系统组成与原理分析

  自稳系统本质是一个**"传感器 → 状态估计 → 串级PID控制 → 电机混控"**的闻名 pipeline（源自 Crazyflie
  固件架构）。整体位于 components/core/crazyflie/，由 stabilizer.c 中的 stabilizerTask 以 1kHz
  驱动。数据流总图：

  IMU/气压计 → sensors_*.c(采样+LPF滤波)
     → stateEstimator()[互补滤波 或 EKF] → state_t(姿态角/四元数/位置/速度)
     → commanderGetSetpoint() → setpoint_t(期望值)
     → controller()：位置环(100Hz)→姿态角环(500Hz)→角速度环(500Hz) → control_t{roll,pitch,yaw,thrust}
     → powerDistribution()混控矩阵 → 4个电机PWM

  下面按模块展开。

  1. 主循环调度（modules/src/stabilizer.c）

  stabilizerTask() 每次被 IMU 数据就绪中断唤醒（主频 1000Hz），依次执行：
  sensorsWaitDataReady();
  stateEstimator(&state, &sensorData, &control, tick);
  commanderGetSetpoint(&setpoint, &state);
  controller(&control, &setpoint, &sensorData, &state, tick);
  powerDistribution(&control);
  各子模块并非都在1000Hz执行，而是靠 stabilizer_types.h 里的降频宏统一调度：
  #define RATE_MAIN_LOOP RATE_1000_HZ   // 传感器采样/主tick
  #define ATTITUDE_RATE  RATE_500_HZ    // 姿态角+角速度PID
  #define POSITION_RATE  RATE_100_HZ    // 位置/高度环
  #define RATE_DO_EXECUTE(RATE_HZ, TICK) ((TICK % (RATE_MAIN_LOOP/RATE_HZ)) == 0)
  即 1000Hz 的 tick 计数器对 1000/目标频率 取模，决定该 tick
  是否执行某子系统——这是一种典型的"分频任务调度"设计，避免让高层慢速环路（如位置环）占用宝贵的高频 CPU
  时间。

  2. 姿态/位置估计（Estimator）

  estimator.c 用函数表在两种实现间切换：

  互补滤波（默认）——estimator_complementary.c + sensfusion6.c：用陀螺仪角速度对四元数积分预测姿态，再用加速
  度计测得的"重力方向"作误差反馈修正积分漂移（Mahony/Madgwick 互补滤波原理）：
  #define TWO_KP_DEF (2.0f*0.4f)   // 比例反馈增益
  #define TWO_KI_DEF (2.0f*0.001f) // 积分反馈增益(修正陀螺零偏)
  姿态融合跑在 250Hz。

  扩展卡尔曼滤波（可选）——estimator_kalman.c + kalman_core.c：13维状态的EKF，100Hz predict +
  各类观测更新（气压/位置/测距/光流等），精度更高但计算量更大。

  两者本质都是把陀螺仪的"高频但会漂移"信息和加速度计/气压计的"低频但绝对准确"信息做频域互补/贝叶斯融合。

  3+4. 姿态控制：角度外环 + 角速度内环（串级PID）

  这是自稳的核心，位于 controller_pid.c + attitude_pid_controller.c：
  // 外环：姿态角误差 -> 期望角速度
  attitudeControllerCorrectAttitudePID(roll, pitch, yaw, rollDesired, pitchDesired, yawDesired,
                                        &rateDesired.roll, &rateDesired.pitch, &rateDesired.yaw);
  // 内环：角速度误差 -> 电机力矩指令
  attitudeControllerCorrectRatePID(gyro.x, -gyro.y, gyro.z,
                                    rateDesired.roll, rateDesired.pitch, rateDesired.yaw);
  原理：外环PID把"当前姿态角"与"期望姿态角"的差转换为"应该以多快的角速度纠正"；内环PID再把这个期望角速度与
  陀螺仪实测角速度的差转换为电机差动力矩。为什么要两层而不是一层？
  因为角速度对陀螺仪信号响应快、噪声相对小、动力学更接近一阶（力矩→角加速度→角速度），适合做快速内环（500Hz
  ）；而角度本身是角速度的积分，变化慢，适合做外环慢环，这样内环可以把角速度环调得很硬（高带宽）而不引入震
  荡，外环则保证姿态收敛到目标——这是经典的双闭环级联控制思想。

  5. 高度/位置控制（Position Controller）

  position_controller_pid.c：位置环→速度环的再次级联：
  setpoint->velocity.x = runPid(state->position.x, &pidX, setpoint->position.x, DT); // 位置误差->期望速度
  float rollRaw = runPid(state->velocity.x, &pidVX, setpoint->velocity.x, DT);        // 速度误差->期望倾角
  attitude->pitch = -(rollRaw*cosyaw) - (pitchRaw*sinyaw);   // 世界坐标速度指令转体坐标倾角
  *thrust = thrustRaw*thrustScale + thrustBase;               // Z速度环输出叠加悬停基准推力
  原理：水平方向没有直接的"力"输出手段，只能通过倾斜机体让总推力产生水平分量，因此水平位置/速度控制器的输出
  实质上是"期望倾角"，再送入第3点的姿态角控制器去执行——即位置控制器是姿态控制器的"外外环"。垂直方向则直接输
  出推力增量。

  6. 传感器与滤波（IMU数据链路）

  hal/src/sensors_bmi088_spi_bmp388.c
  等（按硬件型号切换）：1000Hz采样陀螺仪/加速度计，做零偏估计后经二阶IIR低通滤波：
  #define GYRO_LPF_CUTOFF_FREQ  80  // 陀螺80Hz截止
  #define ACCEL_LPF_CUTOFF_FREQ 30  // 加速度计30Hz截止
  滤波器实现在 utils/src/filter.c（lpf2pInit/lpf2pApply），标准双线性变换设计的二阶Butterworth低通，用于滤
  除机械振动/电机噪声高频成分，避免污染姿态估计和PID微分项。

  7. 电机混控（Power Distribution）

  power_distribution_stock.c，X型四轴混控矩阵：
  motorPower.m1 = limitThrust(control->thrust - r + p + control->yaw);
  motorPower.m2 = limitThrust(control->thrust - r - p - control->yaw);
  motorPower.m3 = limitThrust(control->thrust + r - p + control->yaw);
  motorPower.m4 = limitThrust(control->thrust + r + p - control->yaw);
  原理：把控制器输出的 roll/pitch/yaw
  力矩指令和总推力，按四个电机相对机体中心的几何位置分解成各自的差动推力，本质是一个线性混控矩阵（对角对角
  线电机同向增减实现roll/pitch，对角电机反向增减实现yaw力矩因为螺旋桨转向相反）。

  8. PID 通用实现（pid.c）

  所有6个姿态PID（roll/pitch/yaw各一对角度+角速度）和6个位置PID共用一套实现：
  pid->error = pid->desired - measured;
  pid->outP  = pid->kp * pid->error;
  pid->outD  = pid->kd * lpf2pApply(&pid->dFilter, (error-prevError)/dt); // D项可选LPF抗噪
  pid->integ = constrain(pid->integ + error*dt, -iLimit, iLimit);         // I项限幅防积分饱和
  pid->outI  = pid->ki * pid->integ;
  output = constrain(outP+outI+outD, -outputLimit, outputLimit);
  积分限幅（iLimit）防止长时间偏差导致积分项爆炸（如遥控失联/大风扰动），微分滤波防止对陀螺噪声过度敏感放大
  高频抖动。

  ---

  一句话总结：自稳系统 = 传感器滤波 + 姿态/位置估计（互补滤波或EKF） +
  三级串级PID（位置环→姿态角环→角速度环） + 电机混控矩阵，全部由 1000Hz
  主循环按不同降频比例调度执行。这是标准 Crazyflie 固件架构在 ESP32 上的移植。
