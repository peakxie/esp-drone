posHoldMode 控制流程分析

  这是 ESP-Drone（Bitcraze Crazyflie 2.0 的 ESP32 移植版）的定点悬停模式。核心思路：姿态角设定被替换为速度
  设定，摇杆输入不再直接控制倾角，而是控制机体速度，再由位置/速度控制器换算出对应的姿态角和推力。

  1. 模式定义与进入方式

  - posHoldMode 是 crtp_commander_rpyt.c:83 的静态标志位。
  - setCommandermode()（同文件 91-123 行）在 case POSHOLD_MODE 时：altHoldMode=true;
    posHoldMode=true;，并强制切换状态估计器为 Kalman 滤波器（registerRequiredEstimator(kalmanEstimator)），
    因为定点悬停需要可靠的水平速度/位置估计，普通互补滤波器给不了。
  - 也可通过参数 flightmode.poshold 直接置位（265 行 PARAM_ADD）。
  - 自动触发：sensors_mpu6050_hm5883L_ms5611.c:635 附近，检测到光流模块（PMW3901）自检通过时会自动调用
    setCommandermode(POSHOLD_MODE)；如果只有气压计没有光流，只能进
    ALTHOLD_MODE（水平方向没法定住，代码注释里写明了原因）。

  2. 摇杆输入 → 速度设定值（crtp_commander_rpyt.c:192-260）

  在 posHoldMode 分支里：

  setpoint->mode.x = modeVelocity;
  setpoint->mode.y = modeVelocity;
  setpoint->mode.roll = modeDisable;
  setpoint->mode.pitch = modeDisable;
  setpoint->velocity_body = true;

  setpoint->velocity.x = -pitch/30.0f;   // 前后速度指令（机体坐标系）
  setpoint->velocity.y = -roll/30.0f;    // 左右速度指令（机体坐标系）

  同时因为 altHoldMode 也被强制打开：

  setpoint->mode.z = modeVelocity;
  setpoint->velocity.z = (rawThrust - 32767.f) / 32767.f;  // 上下速度指令（世界坐标系）

  Yaw 独立处理（不受 posHold 影响）：setpoint->attitudeRate.yaw = -yaw，即角速度指令。

  也就是说，四个方向的操控方式：

  ┌───────────┬────────┬───────────────────────────────────┬───────────────────────────────────────┐
  │   动作    │ 摇杆量 │           对应 setpoint           │                 说明                  │
  ├───────────┼────────┼───────────────────────────────────┼───────────────────────────────────────┤
  │ 前进/后退 │ pitch  │ velocity.x = -pitch/30            │ ±30° 摇杆角映射到 ±1 m/s 机体前后速度 │
  ├───────────┼────────┼───────────────────────────────────┼───────────────────────────────────────┤
  │ 左移/右移 │ roll   │ velocity.y = -roll/30             │ 同理映射到左右速度                    │
  ├───────────┼────────┼───────────────────────────────────┼───────────────────────────────────────┤
  │ 上升/下降 │ thrust │ velocity.z = (thrust-32767)/32767 │ 以摇杆中位为悬停，正负决定升降速度    │
  ├───────────┼────────┼───────────────────────────────────┼───────────────────────────────────────┤
  │ 转向      │ yaw    │ attitudeRate.yaw = -yaw           │ 角速度指令，与定点悬停无关            │
  └───────────┴────────┴───────────────────────────────────┴───────────────────────────────────────┘

  velocity_body=true 标记 x/y 速度是机体坐标系下的量，需要后续按当前 yaw 角旋转成世界坐标系速度。

  3. 级联控制器（stabilizer.c → controller_pid.c → position_controller_pid.c）

  主循环 stabilizerTask()（stabilizer.c:268 附近）每 tick 依次做：状态估计 → 取 setpoint → 调用控制器 →
  电机分配。

  控制器 controllerPid()（controller_pid.c:62）内部两级频率：
  - 100Hz：位置/速度环 positionController()
  - 500Hz：姿态角环 + 角速度环

  位置/速度环（position_controller_pid.c:187-247）：

  因为 posHoldMode 下 mode.x/mode.y 是 modeVelocity 而非 modeAbs，位置 PID（pidX/pidY，仅在 POSSET_MODE
  下用）不参与，代码走到：

  setpoint->velocity.x = bodyvx*cosyaw - bodyvy*sinyaw;   // 机体→世界坐标旋转
  setpoint->velocity.y = bodyvy*cosyaw + bodyvx*sinyaw;

  再进入 velocityController()：

  rollRaw  = runPid(state->velocity.x, &pidVX, setpoint->velocity.x, DT);
  pitchRaw = runPid(state->velocity.y, &pidVY, setpoint->velocity.y, DT);
  // 按 -yaw 旋转回机体坐标系
  attitude->pitch = -(rollRaw*cosf(yawRad)) - (pitchRaw*sinf(yawRad));
  attitude->roll  = -(pitchRaw*cosf(yawRad)) + (rollRaw*sinf(yawRad));
  // clamp 到 ±rpLimit（默认20°）

  thrustRaw = runPid(state->velocity.z, &pidVZ, setpoint->velocity.z, DT);
  *thrust = thrustRaw*1000 + thrustBase;   // thrustBase 为悬停前馈推力

  关键点：所谓"定点悬停"实际上是零速度闭环，不是绝对位置闭环——摇杆回中时目标速度为 0，靠速度
  PID（pidVX/pidVY/pidVZ）配合 Kalman
  估计的实际速度做闸门修正，抵消漂移，并不存在世界坐标系下的位置误差反馈环（那是 POSSET_MODE 才用
  pidX/pidY/pidZ）。

  得到的 attitude.roll/pitch（期望倾角）和 actuatorThrust（期望推力）回到 controllerPid()：因为
  mode.roll/mode.pitch = modeDisable，姿态角环直接采用位置/速度环算出来的
  attitudeDesired.roll/pitch，再走：

  角度 PID（pidRoll/pidPitch/pidYaw，500Hz）→ 角速度设定 → 角速度
  PID（pidRollRate/pidPitchRate/pidYawRate）→ control.roll/pitch/yaw（int16），control.thrust =
  actuatorThrust。

  4. 电机混控（power_distribution_stock.c:87-111，X 构型）

  m1 = thrust - roll + pitch + yaw;
  m2 = thrust - roll - pitch - yaw;
  m3 = thrust + roll - pitch + yaw;
  m4 = thrust + roll + pitch - yaw;

  5. 完整链路总结

  摇杆(roll,pitch,yaw,thrust)
    → crtpCommanderRpytDecodeSetpoint()：生成机体系 vx/vy + 世界系 vz + yaw角速度
    → stabilizerTask(): Kalman 状态估计 state.position/velocity/attitude
    → positionController(): 机体速度→世界速度（用当前 yaw 旋转）
    → velocityController(): 速度PID(pidVX/pidVY/pidVZ) → 期望横滚/俯仰角 + 推力（世界速度误差旋转回机体系）
    → 姿态角PID → 角速度PID → control.roll/pitch/yaw/thrust
    → powerDistribution() → 四个电机 PWM

  关键参数（可通过 param 系统在线调整）

  - 速度环增益（组 velCtlPid）：vxKp=25, vxKi=1；vyKp=25, vyKi=1；vzKp=22, vzKi=15
  - 位置环增益（组 posCtlPid，仅 POSSET_MODE 用）：xKp=1.9, yKp=1.9, zKp=1.6；另有
    rpLimit（最大倾角，默认20°）、xyVelMax/zVelMax（默认1.0 m/s）、thrustBase（悬停前馈推力）
  - 姿态角环增益（组 pid_attitude）：roll/pitch Kp=5.9, Ki=2.9；yaw Kp=6.0, Ki=1.0, Kd=0.35
  - 角速度环增益（组 pid_rate）：roll/pitch Kp=250, Ki=500, Kd=2.5；yaw Kp=120, Ki=16.7

  一句话总结：posHoldMode
  把摇杆的俯仰/横滚角输入重新解释为机体前后/左右速度指令，油门输入解释为垂直速度指令，全部经速度 PID
  闭环后再转换为姿态角和推力，最终由姿态/角速度双环 PID
  和电机混控输出到四个电机——本质是"零速度悬停"而非严格的绝对位置锁定。
